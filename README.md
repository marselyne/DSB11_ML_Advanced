#DSB11 — Advanced Machine Learning

Проект по изучению продвинутых методов машинного обучения и построению ML-pipeline.

## 📌 О проекте

В рамках проекта исследовались методы повышения качества моделей машинного обучения, регуляризация, подбор гиперпараметров, ансамбли моделей и автоматизация ML-пайплайнов.

Проект включает практическую работу с:
- regularization
- GridSearch
- metrics
- ensemble methods
- pipelines

---

## 🚀 Реализованный функционал

### 📈 Регуляризация моделей
Исследованы:
- Ridge Regression
- Lasso Regression
- ElasticNet

Проведён анализ:
- переобучения
- устойчивости моделей
- влияния коэффициентов regularization

---

### 🔍 Подбор гиперпараметров

Использован:
- GridSearchCV

Выполнено:
- автоматическое тестирование параметров
- подбор оптимальных hyperparameters
- сравнение результатов моделей

---

### 📊 Анализ метрик

Изучены и сравнены:
- MAE
- MSE
- RMSE
- R² Score

Проведён анализ качества моделей на train/test данных.

---

### 🌲 Ensemble Methods

Исследованы ансамблевые методы:
- Random Forest
- Bagging
- Boosting

Проведено сравнение:
- accuracy
- stability
- overfitting

---

### ⚙️ Pipelines

Созданы ML pipelines для:
- preprocessing
- scaling
- feature transformation
- model training
